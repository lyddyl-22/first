Knights and Knaves
This is a classic logic puzzle type created by mathematician Raymond Smullyan. The rules are simple:
Knights always tell the truth.
Knaves always lie.
All characters know everyone's identity.
Puzzles involve analyzing statements made by characters to deduce who is a knight and who is a knave. Smullyan introduced these in works like What Is the Name of This Book? (1978). They’re widely used in logic education, computer science, and puzzle design.
Example:
A says: "B is a knave."
B says: "We are both knaves."
→ Logical deduction reveals A is a knight, B is a knave.
Variations include "Knights, Knaves, and Normals" (adding characters who can lie or tell truth randomly) and "Portia's Caskets" (combining logic with riddles). These puzzles emphasize propositional logic and consistency checks.
